## 二、背景与痛点：为什么要做「顺路」？

我国有约 8500 万残疾人、3 亿 60 岁以上老年人，以及无数推婴儿车出行的家庭。2023 年 9 月《中华人民共和国无障碍环境建设法》正式施行，但日常生活中「盲道被单车/机动车占压」「过街缘石坡道破损过陡」「室外台阶缺少扶手」等问题依然随处可见。

我们调研了现有政务随手拍、高德轮椅导航、最高检「益心为公」等产品，发现仍有三处空白：
1. **现有地图标「有什么设施」，不标「哪里坏了/被占了」**：轮椅和视障朋友出门前仍可能撞上临时路障。
2. **普通市民「想帮但嫌麻烦」**：向 12345 反映一次问题，通常要回忆具体位置、打字描述现象、查询责任部门、担心拍到路人脸和车牌侵权，5 分钟的门槛劝退了 90% 的善意。
3. **单次反馈难形成持续共治**：反映完没有地图沉淀，也看不到问题最后到底有没有修好。

**「顺路」的定位不是另造一座投诉孤岛，而是做「AI 填单助手 + 动态无障碍避障地图」**：让普通人顺手 10 秒就能完成过去 5 分钟的事，并与 12345 / 12315 / 益心为公形成互补。

## 三、紧扣评审三项基本要求的产品设计

### 1. 简洁易用（打开即用，10 秒完成一次善行）
- **游客免拦路浏览**：打开即可直接浏览城市无障碍动态地图、查看问题详情与体检报告，零门槛体验。
- **三步随手拍**：拍照 → AI 自动完成问题分类（9 大类无障碍问题）、严重程度分级、客观描述撰写、人脸/车牌自动打码与精准地址解析 → 确认提交。
- **一键 AI 填单**：自动援引《无障碍环境建设法》生成规范的 12345 / 12315 反映文本，支持一键复制文本、一键拨打 12345。

### 2. 趣味持续（让善意有回响、有成就感）
- **体检官成长体系**：上报（+10）、被他人确认（+2）、已向部门反映（+5）、路过复查（+20），从「见习体检官」升级至「首席体检官」，配套 7 枚成就勋章与城市/个人排行榜。
- **分享海报与城市报告**：个人可一键生成「体检官影响力海报」，城市可一键生成带无障碍健康度评分的「体检报告长图」，天然适合在同学群、朋友圈传播。
- **众包协作闭环**：其他路人可点「我也遇到」增加问题权重，路过时拍一张「回头看」复查照片，共同推动状态从「待反映 → 已反映 → 已整改」。

### 3. 务实有效（善行价值看得见、可衡量）
- **双向受益**：普通市民顺手一拍，一方面让轮椅、视障群体出门前就能在地图上提前避开路障；另一方面汇总成**城市/区县无障碍体检报告**（含健康度评分、高发类型分布、AI 可落地整改建议与 PDF 导出），可直接递交给学校后勤、街道办或市政部门。
- **可量化成效**：每位用户在个人页都能清晰看见「我标记的问题被多少人确认、推动了多少处整改」。

## 四、技术架构与安全合规亮点

- **多模态 AI 深度融入**：基于通义千问视觉大模型（`qwen3-vl-plus`）与文本大模型（`qwen-plus`），单次视觉请求同步完成**内容审核（拒收无关/不当图）、问题识别分类、严重程度评估、责任渠道推荐（12345/12315）与隐私目标框检测**。
- **全链路隐私与数据安全**：
  - 服务端通过 `sharp` 对 AI 检测出的人脸与机动车车牌实时打码，并支持前端手指手动补涂马赛克；
  - 举报人姓名与电话仅存于用户手机本地 `localStorage`（举报资料卡），绝不上传服务器；
  - 私有草稿图片禁止公网直访，仅上传者本人鉴权可看；
  - 全站采用唯一昵称 + `scrypt` 加盐密码哈希鉴权、资源所有权校验、复查照片二次 AI 审核打码与「2 人确认或发布者核实才标已整改」的防恶意篡改机制。
- **工程化与跨端体验**：React + TypeScript + Tailwind + Hono + SQLite + 腾讯位置服务地图 + Capacitor 原生封装；支持全面屏手势返回、安卓三键虚拟导航栏自适应，并配置 GitHub Actions 实现代码推送自动部署服务器与自动打包 APK。
